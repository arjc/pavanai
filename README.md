# Setup Guide

![Ventoy logo](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcR7UvjpShTbKZdPP-XrOJvW7gxZmRm9U32qLw&s)

**Step 1**: Download and complete the ventoy setup as shown in the official [documentation](https://www.ventoy.net/en/doc_start.html)

**Step 2**: Download the [official release](https://github.com/arjc/pavanai/releases) zip of Pavanai Ventoy Theme.

**Step 3**: Copy the `ventoy` folder directly to the root directory of ventoy. 

![Ventoy copy guide](https://github.com)

**Step 4**: Reboot your system and boot into your ventoy drive.

![Pavanai booted image](https://github.com)

**Step 5**: Check weather all the iso files are intact and you are good to go!
